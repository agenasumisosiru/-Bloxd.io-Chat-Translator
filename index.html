Bloxd Translator

Bloxd.ioのチャットを自動で日本語に翻訳するChrome拡張機能

Chrome extension that automatically translates Bloxd.io chat into Japanese

主な機能

Features

  • Bloxd.io 内の海外チャットを自動でリアルタイム日本語翻訳。
  • Automatically translates overseas chats in Bloxd.io into Japanese in real time.
  • Google翻訳APIの上限により、一時的に翻訳制限がかかる場合があります。
  • Due to Google Translate API limits, translation limits may be temporarily reached.

導入手順 (開発者モード)

How to Install (Developer Mode)

  1. リポジトリのReleasesから .7zファイルをダウンロード
  2. Download the .7z file from the repository Releases
  3. PC上で 7-Zip等のソフトを使いファイルを解凍
  4. Extract the file on your PC using software like 7-Zip
  5. ブラウザで chrome://extensions/ を開き デベロッパーモードをオン
  6. Open chrome://extensions/ in your browser and turn on Developer Mode
  7. 解凍したフォルダを画面に ドラッグ＆ドロップ して完了
  8. Drag and drop the extracted folder onto the screen to complete

主な機能

Features

  • Bloxd.io 内の海外チャットを、指定した主要言語へリアルタイムで翻訳。
  • Real-time translation of overseas chat in Bloxd.io into your chosen primary language.
  • Google翻訳の対応言語を活用し、韓国語・中国語・英語・日本語を含む多言語に対応。
  • Uses Google Translate-supported languages, including Korean, Chinese, English, and Japanese.
  • 導入が簡単で、開発者モードからフォルダを読み込めばすぐ使える。
  • Easy to install: just load the extracted folder in Chrome's developer mode.

導入手順（開発者モード）

How to Install (Developer Mode)

  1. GitHub の Releases から最新の .7z ファイルをダウンロードします。
  2. Download the latest .7z file from the GitHub Releases page.
  3. PC上で 7-Zip などを使って展開します。
  4. Extract the archive on your PC using 7-Zip or similar software.
  5. ブラウザで chrome://extensions/ を開いて デベロッパーモード をオンにします。
  6. Open chrome://extensions/ and enable Developer Mode.
  7. 展開したフォルダを画面へドラッグ＆ドロップして読み込みます。
  8. Drag and drop the extracted folder onto the page to load it.
